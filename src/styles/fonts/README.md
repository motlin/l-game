# Fonts

The latin subset of [Lexend](https://fonts.google.com/specimen/Lexend), as Google Fonts serves it, under the SIL Open Font License 1.1. It is one variable font that covers the 400, 600 and 800 weights the game uses. The page serves it from its own origin so the service worker keeps it for offline play, and `scripts/og-image.ts` renders the social card with it.
